# Automated AI Newsletter with Multi-Agent Architecture

## Description
This project focuses on building an automated AI-driven pipeline to create a structured newsletter with the latest AI news. Using n8n as the core workflow automation tool, the system integrates multiple AI agents to research, summarize, and generate content, delivering a well-crafted newsletter directly to Gmail.

## Key Features:
-  Automated retrieval of AI news from multiple sources
- Custom processing using Python and JavaScript for data cleaning and structuring
- Multi-agent system:
    - AI News Researcher: Gathers and summarizes key insights
    - Image & Subject Creator: Generates relevant visuals and engaging subject lines
    - Newsletter Writer: Composes and formats the newsletter content
- Seamless integration with OpenAI, Perplexity, and Google Workspace
- Fully automated email delivery via Gmail

## Outcome:
The pipeline ensures an efficient and scalable approach to curating AI news while maintaining high-quality content generation. The Gmail output is available in the [Web Page](ai_newsletter.html) and [Gmail page](gmail_ai_newsletter.pdf).
